# smart-Calculator
My first Python calculator project

## Features
- Addition
- Subtraction
- Multiplication
- Division
- division with the ignorance of the zero
- reapted calculation with the help of the while loop.


## python concept used
Variables
input()
float()
if, elif, and else
while loops
Arithmetic operators

## How to run the programme
Open PowerShell in the project folder and run:

py calculator.py


## Example
Enter first number: 10
Enter operator (+, -, *, /): +
Enter second number: 20
Result: 30.0

## What i learned
Through this project, I learned how to take user input, convert strings into numbers, use conditional statements to perform different operations, and create a program that can perform calculations repeatedly.

- Functions
- Conditions
- Error handling
